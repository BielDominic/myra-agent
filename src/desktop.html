ACESSO SEGURO

Cofre de credenciais

Guarde tokens e senhas de aplicativo para que os conectores autorizados da MYRA possam utilizá-los.

LOCAL VAULT
PROTEÇÃO DO COFRE WINDOWS DPAPI

Os segredos são criptografados pelo Windows para a sua conta antes de serem gravados. A interface nunca recebe de volta o conteúdo de uma credencial salva. Outros usuários do Windows não conseguem descriptografar esse cofre.

ADICIONAR OU ATUALIZAR ACESSO

Para Gmail, use uma senha de app com IMAP/SMTP ativados. Não use a senha normal da sua conta Google. OAuth será preferível para integrações completas.

Nada será salvo até você clicar em Salvar.
CREDENCIAIS SALVAS

Carregando cofre local...

Salvar uma credencial não ativa automaticamente qualquer integração. Gmail e Telegram têm conectores específicos; outros serviços precisam de um adaptador compatível. Nunca compartilhe tokens ou senhas no chat.
